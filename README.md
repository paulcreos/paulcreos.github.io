# PaulCreos.com

Official website of Paul Creos, built with Astro and Tailwind CSS. The site combines a
portfolio gallery with articles about craftsmanship, digital fabrication,
technology, and modern Druidry.

## Requirements

- Node.js 20 or newer
- npm

## Local development

```sh
npm install
npm run dev
```

The development server is available at `http://localhost:4321`.

## Quality checks

```sh
npm run check
npm run build
npm run preview
```

`npm run check` validates Astro templates and TypeScript. `npm run build`
generates the production site in `dist`.

## Project structure

```text
src/
├── components/       Shared navigation, hero, category, and article components
├── config/           Site-wide identity and contact information
├── content/articles/ Markdown articles and authoring templates
├── data/             Category definitions
├── images/           Images processed and optimized by Astro
├── layouts/          Base page and article layouts
├── pages/            Static pages, generated routes, RSS, and sitemap
└── styles/           Global theme and responsive styles
public/
├── js/               Gallery lightbox
├── favicon.svg
└── robots.txt
```

## Publishing an article

1. Create a Markdown file in `src/content/articles`.
2. Use a lowercase `kebab-case` filename. The filename becomes the public URL.
3. Add the required frontmatter:

```yaml
---
title: Article title
description: A concise plain-text summary for lists and search engines.
date: 2026-07-30
author: Paul Creos
category: technology
draft: false
---
```

Allowed categories are `works`, `technology`, and `druidism`.

Set `draft: true` while an article is unfinished. Drafts are excluded from
article pages, lists, RSS, and the sitemap.

The `_templates` directory contains optional Obsidian Templater helpers.

## Updating the gallery

Gallery source images are stored in `src/images/gallery`. Import new images in
`src/pages/gallery.astro` and add their descriptive alternative text, caption,
and material. Astro generates responsive WebP variants during the build.

## SEO

Global site data lives in `src/config/site.ts`. Page metadata is generated by
the base layout. Article metadata comes from Markdown frontmatter. The build
also creates:

- `/sitemap.xml`
- `/rss.xml`
- `/robots.txt`
- `/404.html`

If the production domain changes, update both `astro.config.mjs` and
`src/config/site.ts`.
